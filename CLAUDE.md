# Project instructions

## Check the second brain before acting

This repo hosts a personal knowledge base at `second-brain/` (see
`second-brain/README.md`). Before answering a question, giving advice or a
recommendation, or planning/taking any action that involves judgment,
check whether relevant prior thinking already exists there:

1. Skim `second-brain/topics/` for a matching or closely related MOC.
2. Run `second-brain/scripts/search.sh "<keyword>"` to grep titles, tags,
   and body text across `topics/`, `library/`, and `inbox/`.

If something relevant turns up: surface it and reconcile the current
answer with it. Don't silently ignore an existing take, and don't just
restate the old note if circumstances have changed — say explicitly
whether this still holds or has changed.

If nothing relevant exists: say briefly that you checked and found
nothing, then proceed normally.

**Skip this** for purely mechanical requests with no judgment involved
(fixing a typo, running tests, formatting a file) — it's for anything
where the user's own prior thinking could change the answer.
